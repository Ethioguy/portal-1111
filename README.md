# PORTAL 11:11 · Life & Training Tracker

Kicked off on 11.11.2026 at 11:11 PM.

A mobile-first web app for tracking the 12 life categories and a 12-week Hyrox-style plan at home
(resistance bands, two adjustable dumbbells, pull-up bar, Maxi Climber,
bike, daily 2–3 mile run).

## Features
- **Today** – the day's planned session (auto-adjusts by week and phase), tap-to-check exercises, run/bike log with pace, daily habits, weight and waist, notes
- **Timer** – stopwatch with laps (race simulations), superset rest, EMOM, 400 m intervals, mobility, custom intervals with 3-2-1 beeps
- **Life** – the 12 life categories: daily check-in, 1–10 ratings, your vision, reasons and actions for each
- **Week** – 7-day completion grid and the week's plan
- **Progress** – streak, total miles, sessions, weight trend, 4-weekly tests, race-simulation times
- **Setup** – plan start date, units, backup and restore

Data is saved in the browser (localStorage). Installable as a home-screen app with offline support on GitHub Pages.

## Run it
Open `index.html`, or enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

General fitness guidance, not medical advice.
